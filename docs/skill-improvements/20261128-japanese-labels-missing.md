# イベント名が日本語で表示されない（2026-11-28）

コーヒーショップのセッション（`eventstorming-20261128-1105`）で、オーナーから出た指摘。
「イベントが日本語で表示されないね」。

## 何が起きたか

- フェーズ 3 で、シナリオ（`scenarios[]`）を 14 本まで書いた。各シナリオの `cmd` / `evt` は英語の識別子だけで、**日本語ラベルはどこにも登録されていなかった**。
- 日本語ラベルの置き場は `contexts[].lang`（`cmds` / `evts` / `actors` など）。ところが、この時点で `contexts[]` が**空**だった。置き場の BC そのものが無かったので、ラベルを書きようがなかった。
- そのため、Artifact（HTML）のフロー図やイベント名は、英語の識別子のまま表示された。
- オーナーに指摘されて初めて、`contexts[]` を 6 つ作り、`lang` にラベルを登録した。

## 原因

### 1. SKILL.md の手順に、`contexts[]` をいつ作るかが書かれていない

- フェーズ表の「3. イベント発見」には「`scenarios[]` 仮 entries ＋ `contexts[].lang` 新規識別子」とある。つまりフェーズ 3 で `lang` に書くことになっている。
- 一方、`contexts[]` を宣言するのは、表の上では「4. CMD→EVT→POLICY チェーン」と「4.5. BC 境界」。`lang` の書き込みが、`contexts[]` の宣言より**先**になっている。
- 「フェーズ 3 の `ctx` は仮置きで良い」という節はあるが、仮置きした `ctx` に対応する BC を `contexts[]` に作る指示がない。

### 2. 検査はあるが、書き込みのたびには走らない

- `dmlctl check --check=language_coverage` は、ラベル未登録を正しく検出する。再現で確認した（`contexts[]` が空のまま `cmd` / `evt` を持つシナリオを足すと、CMD と EVT の未登録がエラー 2 件で出る）。
- ただし dmlctl の自動の後処理は、schema 検証とビルドまで。`language_coverage` などの構造チェックは走らない。
- このセッションでは、速度のために書き込みへ `--no-postprocess` を付けていた。**`check --all` を回すまで、ラベル抜けが表に出なかった**。

### 3. HTML 側が、ラベル抜けを静かに英語で出す

- ラベルが無いとき、ビルダーは英語の識別子をそのまま出す。HTML 上に「日本語ラベル未登録」の目印は出ない。
- 日本語の読み手には、モデルの不備ではなく、表示の仕様に見える。

## 提案

### A. 手順（SKILL.md、優先度 高）

- フェーズ 3 で、シナリオに仮の `ctx` を書くときは、**同じターンのうちに `contexts[]` に仮の BC を作る**（`name` と `label_ja` だけでよい）。`lang` の置き場を先に用意する。
- シナリオ（`cmd` / `evt` / `actor`）を足すたびに、所属 BC の `lang.cmds` / `lang.evts` / `lang.actors` へ日本語ラベルを**同時に**登録する。「aggregates と policies を足したら lang にも同時登録」（SKILL.md 215 行付近）の規則を、cmd・evt・actor にも広げる。
- 1 つの書き込みの塊（シナリオ追加と lang 登録）が終わるたびに、`dmlctl check <file> --check=language_coverage` を回す。

### B. dmlctl（優先度 高）

- `add --to=scenarios` のとき、`ctx` が `contexts[]` に無ければ、**警告を出す**（または仮の BC を自動で作る `--create-ctx` を付ける）。
- 後処理に、`language_coverage` だけでも含める。`--no-postprocess` を連ねる速い書き方でも、**最後の 1 回は後処理を回す**よう、SKILL.md の「複数コマンドの連鎖はシェル関数で」の説明に明記する。
- あるいは、`dmlctl add --to=scenarios` に `--label-cmd` / `--label-evt` を足し、シナリオとラベルを 1 コマンドで書けるようにする。

### C. ビルダー（優先度 中）

- ラベル未登録の識別子は、HTML 上で英語のまま出し、**淡い警告の印**（例: 識別子の横に「訳未登録」）を付ける。
- ページ上部に「日本語ラベル未登録: N 件」を出す。Artifact では質問パネルの近くに置けば、進行役が気づける。

## 受け入れ条件

- フェーズ 3 でシナリオを足した直後の Artifact で、イベント名・コマンド名・担い手が、日本語で表示される。
- `contexts[]` が空のままシナリオを足すと、dmlctl が警告を出す。
- ラベルが未登録のとき、HTML 上に目印が出る。

## コスト

小〜中。手順の追記（SKILL.md）と、dmlctl の警告 1 本で大半は防げる。ビルダーの目印は、描画の改修が要るため別に判断する。
